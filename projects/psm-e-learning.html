Overview

The PSM E-Learning Management System was developed as my Final Year Project. It is a full-stack educational platform built from the ground up to solve the challenges of managing online learning resources, tracking student progress, and issuing verifiable credentials.

Key Features

Role-Based Access Control

Distinct, secure workflows and dashboards for Students, Instructors, and Administrators, ensuring data isolation and privacy.

Course Management

Instructors can seamlessly upload materials, create assignments, and deploy structured assessments.

Payment Gateway

Secure gateway integration for processing course enrollment fees via Stripe.

QR-Verified Certificates

Automated PDF certificate generation upon course completion, featuring cryptographic, scannable QR codes for verifiable authenticity by employers.

Technical Architecture

The backend architecture relies on Java Servlets and JSP running on Apache Tomcat. The entire application is containerized using Docker to ensure consistency across development, testing, and production.
