Overview

MasakJerr! is a recipe management platform designed to help users organize, share, and discover culinary creations. It demonstrates full-stack development patterns through recipe CRUD (Create, Read, Update, Delete) workflows backed by MySQL.

Key Features

Recipe Management (CRUD)

Users can seamlessly create new recipes, upload instructions, update ingredients, and delete entries from their cookbook.

Data Persistence

Reliable and normalized data storage using relational mapping against a MySQL database.

User Profiles

Registration and login flows to keep user data isolated and private.

Java Web Backend

Uses Java Servlets for request processing and business logic, JSP pages for the web interface, and MySQL for persistent data storage.

System Architecture Pipeline

Full-stack MVC recipe persistence pipeline managing user authentication, CRUD operations, ingredient normalization, and relational storage.
