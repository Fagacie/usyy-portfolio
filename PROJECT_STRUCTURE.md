# Portfolio structure

The production site currently uses a static multi-page HTML architecture served from
the repository root. `index.html` is the homepage; `about.html`, `work.html`,
`awards.html`, `contact.html`, and `research.html` are secondary routes. Project
case studies live under `projects/`.

Shared behavior is generated by `js/components.js` and page interactions live in
`js/main.js`. Shared styles are in `css/style.css`; page-specific styles are in
`css/home.css`, `css/work.css`, `css/secondary-pages.css`, and
`css/case-study.css`. `css/redesign.css` is the final visual token and override
layer for the approved three-colour design system.

Assets are stored in `assets/`, with deployment-facing copies under `public/assets/`.
The repository also contains a React/Vite implementation under `src/`; it is not
mounted by the current static `index.html` and must not be treated as the active
site without an explicit architecture decision.
